# Aula Isabel — Acceso Universidad +45, Andalucía 2027

Curso HTML estático, responsive y autocontenido (sin librerías externas). Se puede abrir `index.html` localmente o publicar la carpeta completa en un servidor estático / GitHub Pages.

## Contenido
- 12 unidades (100 horas de dedicación recomendada); 60 preguntas de autoevaluación con corrección y requisito de 4/5 para avanzar.
- Explicaciones con ejemplos, actividades individuales, guiadas y de diálogo, resúmenes, soluciones desplegables y cuaderno personal.
- 3 simulacros **originales** de doble ejercicio con reloj de 60 minutos, orientaciones de corrección y rúbrica didáctica.
- Plan de 20 semanas, glosario de 47 términos, enlaces oficiales, impresión del manual de estudiante y solucionario de estudio.
- Progreso guardado mediante `localStorage` en el dispositivo; permite exportación/importación manual JSON, sin servidor.

## Uso y limitaciones
1. Abrir `index.html` en un navegador moderno.
2. Superar la autoevaluación al final de cada unidad (al menos 4 de 5 respuestas correctas) para desbloquear la siguiente.
3. Resolver por escrito las actividades y simulacros antes de ver las soluciones de orientación.
4. Revisar las redacciones con una persona formada; el sitio **no** asigna automáticamente una nota fiable a textos abiertos.
5. Acceso universitario **no garantiza plaza** en el grado; después se requiere admisión.
6. La preparación se basa en el temario y procedimiento oficiales consultados el 18/11/2026; comprobar posibles actualizaciones y detalles de inscripción.

## Desarrollo y despliegue
Archivos: `index.html`, `styles.css`, `course-data.js` y `app.js`. No se requiere compilador ni dependencias.

Para publicar en GitHub Pages, subir los cuatro archivos a una carpeta o a la raíz de un repositorio con Pages activado y probar la URL real. Para activar el **subdominio propio** `acceso45.rubenmunozdocente.digital` es necesario configurar GitHub Pages para la publicación de un sitio exclusivo y el registro CNAME en el DNS del dominio. **No basta con crear un archivo CNAME en una subcarpeta.**

Autoría didáctica: Rubén Muñoz Valadés. No es una web oficial ni un título académico.
