# Aula Isabel — Acceso a la Universidad para mayores de 45 años (Andalucía, 2027)

Curso web de preparación autónoma con 12 unidades, 100 horas de dedicación recomendada, 60 preguntas de autoevaluación, 3 simulacros, plan de estudio de 20 semanas, actividades resueltas, glosario y entrevista.

## Abrir el curso
Ruta de GitHub Pages (sujeta a que Pages esté habilitado para el repositorio):
https://rumuva.github.io/acceso45/

Archivos necesarios: `index.html`, `styles.css`, `course-data.js` y `app.js`. No hay dependencias externas.

## Cómo estudiar
Empieza por la unidad 1, repasa los temas, resuelve las actividades antes de abrir el solucionario y contesta la autoevaluación. Es necesario acertar al menos 4/5 para desbloquear la siguiente unidad en este navegador. El progreso se guarda en almacenamiento local y puede exportarse/importarse.

Los simulacros son **originales y de entrenamiento**, no copias oficiales. Las redacciones y la entrevista requieren valoración humana.

## Dominio personalizado
Subdominio deseado: `acceso45.rubenmunozdocente.digital`. No se activa automáticamente por crear la carpeta `acceso45` en este repositorio. Para utilizar el subdominio como URL real hay que desplegar el curso en un sitio Pages independiente con dominio personalizado y crear el registro CNAME correspondiente en la zona DNS del dominio; alternativamente alojar estos archivos directamente en el subdominio de Hostinger. Confirmar funcionamiento HTTPS antes de compartirlo.
